# Rails gaps after the portal redesign

The portal now follows Paper wherever the current API allows. What Paper shows
and Rails cannot supply yet is tracked in GitHub issues, one per area. Each
issue has the item checklist. Each set's report in `reports/` has the detail
and the Paper artboards.
